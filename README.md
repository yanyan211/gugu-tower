# 菇跳塔 · GU TIAO TA

咪菇的无限跳塔小游戏：左右滑动转动高塔，让咪菇一路往下掉。连续穿过 4 层进入冲刺，可以直接击碎下面的平台，越往下越难。

**在线玩：** 把这个仓库开启 GitHub Pages 后，打开 `https://你的用户名.github.io/仓库名/`

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 整个游戏（模型、贴图、字体、标题图都已经打包在里面） |
| `favicon.png` | 网页图标（菇跳塔标题） |
| `logo.png` | 菇跳塔标题图，README 顶部用 |
| `.nojekyll` | 让 GitHub Pages 原样发布，不要删 |

## 开启 GitHub Pages

仓库 **Settings → Pages → Build and deployment**：Source 选 **Deploy from a branch**，Branch 选 **main**、文件夹 **/(root)**，保存。等一两分钟就能打开。

## 账号和排行榜

登录、注册、排行榜连接的是 `https://api.cino1018.com/api/tower`，需要先在服务器上装好菇跳塔服务；没装好时游戏照常能玩，只是登录和排行榜用不了。
